# GateKeeper AI

GateKeeper AI è un sistema professionale di riconoscimento targhe progettato per Raspberry Pi.

## Obiettivi

- Riconoscimento targhe offline
- Controllo cancello tramite GPIO
- Dashboard Web
- Integrazione Home Assistant
- Database SQLite
- API REST
- Logging avanzato

## Hardware supportato

- Raspberry Pi 3
- Raspberry Pi Camera IMX219
- Raspberry Pi Camera Module 3
